# 🏥 Patient Readmission Analysis

> Exploring healthcare data to identify factors that contribute to patient readmissions.

## 📖 Overview

This project analyzes a patient readmission dataset using Python and Pandas to uncover trends, patterns, and factors associated with hospital readmissions.

The objective is to demonstrate practical data analytics skills by cleaning, exploring, and visualizing healthcare data to support data-driven decision making.

---

# 🎯 Objectives

- Understand patient demographics
- Analyze readmission rates
- Identify important variables
- Perform exploratory data analysis (EDA)
- Build meaningful visualizations
- Practice healthcare data analytics

---

# 📊 Dataset

The dataset contains patient information including:

- Patient ID
- Age
- Gender
- Diagnosis
- Length of Stay
- Number of Previous Admissions
- Treatment Cost
- Readmission Status

*(Dataset may be modified for educational purposes.)*
